# 0.6.0 격리 검증 결과

재고 업무 통합과 관리 회계 기능을 구현하고 기존 상품·옵션·입고 배치·QR 흐름을 보존했다. 승인된 기준은 출고 시 관리매출·FIFO 대응 원가 인식, 과입금 예수금 분리, 실제 보유 물품의 기초층 이후 FIFO 적용이다. 기준 버전은 `management-shipment-fifo-opening-2`. 미등록 원가·미연결 입출금·적용 전 거래 등이 있으면 관리손익은 **미확정**이며 등록 금액 참고소계만 제공한다. 정식 회계 마감·세무 장부가 아니다.

## 검증 환경

Windows 격리 복사본, PHP **8.4.26**, MySQL **8.4.11**, 합성 DB만 사용했다. 대상 PHP **8.3.6 / MySQL 8.0.46**과 다르며 해당 대상 버전에서 실행한 결과가 아니다. DB 읽기·쓰기 연결과 포트 33319를 가드했다. 운영 서버·DB·자격정보를 사용하지 않았고 commit·push·배포하지 않았다.

## 결과

- 최종 Feature: **230 tests / 61,002 assertions**, 3분 14.162초, 최대 142MiB. 별도 집중 검증 12 tests / 3,705 assertions. JS 12개, 설치 Smoke 2개 / 29 assertions 통과.
- 일자 분리 주문·증분 입금·부분취소·출고·반품·환불, 과입금 분리, 동일 키 재시도, 업체/권한 격리, 부분 지급·회수, CNY 정확 연산, 원금/수수료 분리, 수령 전 예상 자금 사용 금지, 월말 반복 비용 검증.
- 서로 다른 실제 QR 출고의 FIFO 배분, 예약·A/S 처리, 미등록 기초 원가 유지, 손실/복구, 실사 동시 변경 충돌·예약 물품 차감 금지 검증.
- 보고서 불변성·해시 검증·새 버전 보존·관리 잠금과 재개방·최신성 확인, 실제 확인 계좌의 암호화 스냅샷과 사후 계좌 변경 보존 검증.
- 실제 Chrome 1440/1920/390px에서 비용 모달·자금·이체·보고서 저장·재출력·분할 합계 일치, 1/501페이지, 기존 저장 운영 보고서 재조회 통과. 상품 등록 4옵션·KRW/CNY 입고·품질 상태/이력·실사 확정·QR 미완료/재출력 흐름도 통과.
- A4 세로 첫 부분 40쪽, 가로 마지막 부분 51쪽 PDF 생성. 모든 페이지 텍스트 존재 및 상세 순번 연속성, 첫/끝 페이지 시각 확인. 실제 종이 프린터는 실행하지 않았다.

## 성능

단일 로컬 실행이며 동시 부하 벤치마크는 아니다. 쿼리 수는 바인딩/쿼리 전체 로그를 저장하지 않는 DB listener로 셌고 메모리는 PHP 프로세스 peak다.

합성 규모: 상품 55, 옵션 616, 물품 **4,365**, 재고 이동 **25,374**, 주문 **2,602**, 주문 상세 **10,405**, 비용 **10,008**, 자금 원장 16, 저장 보고서 24, 저장 상세 292,682행(측정 시작 시점). 원가 미등록 4,312개/기초층 대기 596옵션 등 누락도 숨기지 않고 표시한다.

## 업데이트·복구·배포 대상

원본 `e3e54760d`의 0.2.0 소스 **171파일 SHA256**을 확인하고 원본 스키마로 상품·입고 3개·주문·입금·출고·암호화 계좌를 생성했다. 공식 `plugin:update --source=bundled --force`에서 **0.2.0 → 0.6.0**을 확인했다. 기존 23테이블의 모든 기존 컬럼/행 해시, 입고·입금·출고 재시도 응답, 계좌 복호화가 보존됐고 미확정 기초층 2개와 신규 저장/재조회가 통과했다. 원본 최초 설치의 seeder 오토로드 누락은 격리 실행 래퍼의 classmap 등록으로만 보완했으며 원본 패키지는 수정하지 않았다. 이전 0.5 기준 데이터 보존 검사도 별도 증거로 남겼다.

신규 migration **000008~000011**은 실사·FIFO·관리 회계·자금 날짜 인덱스·실제 계좌 확인 스냅샷을 추가한다. 이전 000005~000007도 0.2 업데이트 경로에서 실행된다. 기존 원가/실제 입출금 계정을 추정해 채우지 않는다. 사용 기록이 있으면 down을 거절한다. 복구는 동일 시점 코드·DB·첨부·암호화 키 전체 복원 또는 수정 버전 전진 업데이트로 수행한다.

공식 production 빌드, 5종 버전 manifest 0.6.0 및 dist, route:cache, vendor:verify 통과. 배포 대상은 `plugins/_bundled/yutiv-live_commerce/` 전체이며 실제 배포하지 않았다. 배포 절차와 집계 기준은 [ACCOUNTING_060.md](ACCOUNTING_060.md), API는 [api/accounting.md](api/accounting.md), 원본 수치·로그·PDF는 [검증 증거](verification/accounting060/)에 있다.

외화 자금 기말 재평가/확정 환차손익·세금·감가상각은 계산하지 않는다. 과거 FIFO를 재구성하지 않으며 누락 원가는 미확정이다. 이체 취소는 미출금 취소 또는 전액 원금 반환 확인이며 부분 반환/환전 차액 정산은 이번 구현에 포함하지 않는다.

# Changelog

## [0.8.0] - 2026-10-21

### Changed
- 최종 캡처 피드백: 방송 작업/초기화 보조 버튼, 전표 전체 합계 카드와 페이지 소계 구분, 권한별 업무 7개를 4개 보조 메뉴로 구성. 모바일 KPI의 반복 기간 제거·도움말·큰 금액 폭 확장, 장부 터치 스크롤 안내/경계 표시와 A4 보완. 이번 표시 보완에서 src/database 128개 파일 바이트 동일.
- 회계 현황 최종 기준: 제목/기간 필터 → 탭 → 흰색 4개 KPI → 기준 안내 → 통화별 기간 장부 → 접힌 설정. 현재 미수금과 기간 금액 구분, CNY 저장 원금/환산 비용 분해와 기존 비용 대사. 상세: docs/ADMIN_UI_080_FINAL.md.
- 판매자 주 메뉴를 기존 메뉴 원본과 역할 권한으로 공통화. 회계 하위 화면에서도 같은 항목·순서·명칭·너비와 회계관리 활성 표시를 유지하고 모바일 접이식 메뉴 제공.
- 방송관리 3개·회계관리 6개 탭, 기간 필터, 관리 실적/현금 구분 카드, 금액 표시와 업무별 입력 패널을 공통 운영 디자인으로 정리.
- 회계 초기 설정을 상태 안내와 명시적 확인 대화상자로 축소. 미설정 조회에서는 감사 기록을 쓰는 보고서 집계를 실행하지 않아 조회·열기만으로 DB를 변경하지 않음. 적용 이후 기존 조회 감사·시작/마감/재개 정책 유지.
- 내부 집계 기준과 거래 식별자는 상세 정보로 이동하고 기존 상세 표·전체 합계·페이지네이션·저장 보고서 데이터 보존.

### Fixed
- unsigned 금액에 정수 음수 부호를 곱해 실패하던 역분개 조회를 DECIMAL 부호 연산으로 보완. 계산·환산·반올림·저장 보고서 정책 유지.
- 기본 밑줄/방문 색으로 보이던 방송 탭과 회계 화면별로 교체되던 메뉴, 불균일한 필터 입력 크기 수정.
- 화면 탭의 선택자 우선순위 때문에 인쇄에 탭이 나타나는 충돌 수정. A4에서 관리자 메뉴·탭·작업 버튼 제외.

### Scope
- FIFO·관리매출·원가·환율·반올림·원장·주문 스냅샷·불변 보고서·인센티브 계산 변경 없음. 신규 migration 및 데이터 변환 없음.
- 코어 공개 API 변경 없음. 다른 번들 확장의 의존 선언을 전수 검색했으며 이 플러그인을 소비하는 확장이 없어 최소 버전 동기화 대상 없음.
- 공식 빌드 및 격리 0.7.0→0.8.0 업데이트. 검증·전후 화면·배포 대상: docs/ADMIN_UI_080.md.

## [0.7.0] - 2026-10-21

### Added

### Fixed
- 쇼호스트 명부 전체가 신규 방송 참여자로 제출되던 문제를 수정. 신규 참여자는 미선택이며 기존 저장 참여자·요율은 보존.

### Changed
- 방송·채널·쇼호스트·방송 판매상품 메뉴를 방송관리로 통합. 기존 URL 권한·판매 링크·주문 스냅샷·정산 계산은 보존.
- 기존 스키마를 사용하므로 migration 없음. 코어 공개 표면 변경 없음. 다른 번들 소비 확장 의존성 검사 후 최소 버전 변경 대상 없음.

## [0.6.0] - 2026-10-21

### Added
- 상품에서 시작하는 실사 초안·재확인·QR별 확정 및 재고 변경 충돌 감지.
- 출고 기준 관리매출·독립 FIFO 기초층/배분/반품·손실 복원, KRW/CNY 거래별 고정 환율.
- 회계관리: 지출 분류·분할 지급/회수·정기 미지급·실제 자금·단계별 이체·예수금·증빙.
- 불변 관리 보고서·100건 분할 재출력·사유 있는 기간 잠금/재개방과 권한 분리.

### Changed
- 재고 업무 진입은 상품 목록으로, 통계·장부·입금계좌는 회계관리로 통합. 기존 URL/저장 운영 장부는 보존.
- 회계 기준 적용 후 입금/환불은 누적 덮어쓰기 대신 이번 실제 금액·자금·기록일을 추가.
- 재무 조회는 비잠금 일관 스냅샷, 유지관리는 기존 명령의 제한 안에서 처리.
- 공개 API 추가/확장을 소비하는 다른 번들 확장 의존성 없음. 코어 공개 표면 변경 없음.

## [0.4.0] - 2026-10-20

### Added
- 업체·기간·상품 조건의 전체 합계와 20개 옵션 단위 화면 페이지네이션, 불변 운영 보고서 저장·목록·재조회 및 100행 단위 전체 상세 분할 인쇄.
- 보고서별 업체명·시간대·기간·집계 기준 버전·생성 시각·생성자·현재 분석·집계 결과와 당시 상세 보존. 재생성은 별도 UUID 버전이며 재출력은 원본 주문/상품을 다시 읽지 않는다.
- `live_reports`, `live_report_rows` 및 기간/원장 조회 복합 인덱스 추가 migration. 기존 업무 행·QR·원장 변경 없음.

### Changed
- 기간 발생 주문액·누적 입금 확인액 차이·취소·반품·환불 기록과 현재 미입금/현재 주문 상태/현재 잔여 상품금액을 구분. 기간 순매출 및 회계상 매출 인식은 제공하지 않음.
- 누적 수량 상한 대신 DB 조건 조회·집계와 전체 전이 검증을 사용. 보고서 조회/생성은 REPEATABLE READ의 비잠금 일관 읽기이며 업체 쓰기 잠금을 획득하지 않는다.
- 상품 조건의 주문액/차감/재고는 해당 상품, 입금·환불·현재 미입금은 해당 상품 포함 주문 전체 기준으로 명시.
- 공개 서비스/라우트 확장을 검토하고 번들 manifest 소비자를 전수 스캔: 의존 확장 없음. 코어 공개 API 및 g7_version 변경 없음.

### Fixed
- DB 집계로 전환하면서도 상태·위치·최초 입고의 엄격한 비교가 collation의 대소문자 무시 규칙으로 완화되지 않도록 바이트 단위 비교 및 회귀 검증 적용.

## [0.1.0] - 2026-09-10

Phase 0 기술 스파이크. 라이브커머스 기능은 없습니다.

### Added

- `Route::domain()` 기반 TeeWide 도메인 라우트 (`teewide.portal`, `teewide.live.tenant`).
  코어 `PluginRouteServiceProvider` 가 프리픽스를 강제하므로 프로바이더 `boot()` 에서
  직접 등록합니다.
- `TeeWideHostGate` — TeeWide 호스트에서 기존 쇼핑몰 SPA·검색·이커머스 API 가 노출되지
  않도록 차단합니다. 코어 확장 미들웨어 자가 게이트(`everything`/`before_core`)로 붙습니다.
- `ConfigureTeeWideSession` — TeeWide 요청의 세션 쿠키를 `teewide_session` /
  `.teewide.com` 으로 바꿉니다. **StartSession 보다 먼저** 실행되도록 라우트 자체 스택의
  첫 자리에 둡니다.
- `TeeWideHost` — 포트·대문자·후행 점·공백·IPv6 를 정규화하고, 정확히 일치할 때만
  TeeWide 로 판정합니다.
- Phase 0 진단 라우트(JSON). `TEEWIDE_DIAGNOSTICS=false` 면 등록되지 않습니다.

### Notes

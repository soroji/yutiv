# Changelog

## 1.0.0 — 2026-10-09

- 본사 관리자 신규 상품 XLSX 검증·미리보기·비공개 등록·비동기 진행/결과 및 실패 재시도.
- 기존 상품 검증/저장·재고·미디어 서비스를 재사용하고 파일/이미지 보안 제한 및 중복 예약 추가.
- 수동/엑셀 일반 상품의 공통 단일 판매 단위 저장을 사용하도록 sirsoft-ecommerce >=1.2.1을 요구합니다. 옵션 없는 상품은 옵션 시트 행을 요구하지 않습니다.
- 기존 결제·메뉴·지원·사용자 템플릿의 API 시그니처와 옵션 상품 동작은 유지되므로 해당 소비 확장의 기존 최소 버전 제약은 유지합니다. 코어 공개 API는 변경하지 않습니다.

# Changelog

## [0.1.2] - 2026-10-11

### Changed
- 운영 화면의 상태별 안내와 이름 기반 검색·선택, 이미지 업로드를 개선했습니다.

## [0.1.1] - 2026-10-11

- 가입 증명의 일회성 소비 고유 키와 회원 INSERT의 연결/트랜잭션 검사를 추가합니다.
- 스냅샷의 순서 의존을 UUID 조회로 교체하고 환불 저장 시 검토를 즉시 캡처해 지연 이벤트 지급을 차단합니다.
- 유지보수 명령을 공통 MySQL 세션 잠금으로 직렬화하고 outbox 배치·실행 시간 입력을 제한합니다.
- 일반 closure 검사는 전역 revision 쓰기 잠금을 잡지 않습니다. 명시적 복구만 쓰기 잠금을 사용합니다.
- BCMath 설치·활성화 사전 검사와 전용 systemd 배포 문서를 추가합니다. ecommerce >=1.3.1 필요.

## [0.1.0] - 2026-10-11

- YUTIV 회원 전용 개인 스토어, 귀속 증명, adjacency/closure, 본사 승인·변경 이력.
- 상품 개별 포함·제외/카테고리 하위 포함, 공개 `/store/{slug}`, 독립 `/store-office`, 본사 관리 화면.
- KRW 정수 P의 재귀 배분·불변 주문 스냅샷·트랜잭션 outbox·멱등 원장·회수 부족·미래 적립 상계.
- outbox 처리·현재 상태 재등록·closure 검사/명시적 복구·원장/잔액 대사 명령.
- `sirsoft-ecommerce >=1.3.0`의 원본 라인 및 트랜잭션 내부 확장 계약에 의존합니다. 코어나 TeeWide 공개 API를 변경하지 않습니다.

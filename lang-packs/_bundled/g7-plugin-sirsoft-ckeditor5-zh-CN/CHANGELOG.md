## [1.0.0] - 2026-09-08

### Added

- G7 CKEditor 5 플러그인(sirsoft-ckeditor5) 중국어 간체(zh-CN) 언어팩을 신규 제공합니다. 에디터 설정 화면, 업로드 이미지 관리 화면, 이미지 업로드 검증 메시지가 간체 중국어로 표시됩니다.
- 백엔드 번역 1종(messages)과 프론트엔드 번역 1종을 추가했습니다 — 이미지 업로드·삭제·정리 메시지와 관리자 업로드 이미지 목록·필터·모달 문구 전체.
- 초기 데이터 번역 2종을 추가했습니다 — 권한 트리 4항목, 플러그인 표시명·설명.
- 툴바 유형 키(minimal/standard/full)·CDN 호스트·artisan 명령 문자열은 원본 그대로 보존했습니다.

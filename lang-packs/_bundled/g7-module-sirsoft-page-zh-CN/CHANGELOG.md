## [1.0.0] - 2026-09-08

### Added

- G7 페이지 모듈(sirsoft-page) 중국어 간체(zh-CN) 언어팩을 신규 제공합니다. 페이지 관리 화면과 페이지 등록·수정 폼, 버전 이력, 첨부파일, 검증 메시지가 중국 본토 표기 기준의 간체 중국어로 표시됩니다.
- 백엔드 번역 3종을 추가했습니다 — 활동 로그(액션·설명·필드 라벨), 페이지·첨부파일 작업 메시지, 검증 메시지 전체.
- 프론트엔드 번역 2종(진입 파일 1종 + partial 1종)을 추가했습니다 — 레이아웃 편집기 데이터 소스 라벨과 관리자 페이지 관리 화면 문구 전체.
- 초기 데이터 번역 3종을 추가했습니다 — 권한 트리 6항목, 관리자 메뉴 1종, 모듈 표시명·설명.
- 슬러그(`slug`)·발행 상태 enum(`html`/`text`, `asc`/`desc`, `created_at`/`published_at`)·route 경로·placeholder 는 원본 그대로 보존했습니다.

## [1.0.0] - 2026-09-08

### Added

- G7 게시판 모듈(sirsoft-board) 중국어 간체(zh-CN) 언어팩을 신규 제공합니다. 관리자 화면과 사용자 화면의 게시판 문구, 검증 메시지, 알림 메일이 중국 본토 표기 기준의 간체 중국어로 표시됩니다.
- 백엔드 번역 7종을 추가했습니다 — 게시판·게시글·댓글·첨부파일·신고·권한·환경설정·활동 로그·알림·SEO·검증 메시지 전체.
- 프론트엔드 번역 19종을 추가했습니다 — 게시판 관리·게시글 관리·신고현황·환경설정·게시판 유형·대시보드·이커머스 문의 연동 화면과 사용자 화면 문구.
- 초기 데이터 번역을 추가했습니다 — 게시판 유형 3종, 관리자 메뉴 4종, 권한 트리 17항목, 알림 정의·템플릿 7종, 모듈 표시명.

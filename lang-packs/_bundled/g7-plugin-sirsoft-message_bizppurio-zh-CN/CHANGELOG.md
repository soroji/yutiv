## [1.0.0] - 2026-09-08

### Added

- G7 비즈뿌리오 메시지 발송 플러그인(sirsoft-message_bizppurio) 중국어 간체(zh-CN) 언어팩을 신규 제공합니다. 발송 설정·발송 이력·활동 로그 화면이 간체 중국어로 표시됩니다.
- 백엔드 번역 3종(activity_log·messages·result_codes)과 프론트엔드 번역 1종을 추가했습니다 — 발송 결과 코드 설명과 관리자 화면 문구 전체.
- 초기 데이터 번역 3종을 추가했습니다 — 권한 트리, 알림 정의·템플릿, 플러그인 표시명·설명.
- SMS/LMS/MMS/알림톡 등 발송 유형 키와 비즈뿌리오 결과 코드 값은 원본 그대로 보존했습니다.

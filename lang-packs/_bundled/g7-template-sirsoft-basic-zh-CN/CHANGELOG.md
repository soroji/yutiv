# Changelog

이 언어팩의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [1.0.1] - 2026-09-08

### Added

- 홈 환영 카드 배지 문구(`home.welcome_badge`) 번역을 추가했습니다. 템플릿에서 영어로 하드코딩돼 있던 "Welcome" 이 번역키로 바뀌면서 필요해진 키입니다.

## [1.0.0] - 2026-09-08

### Added

- G7 기본 사용자 템플릿(sirsoft-basic) 중국어 간체(zh-CN) 언어팩을 신규 제공합니다. 홈·게시판·쇼핑몰·마이페이지·회원가입/로그인·약관 화면 문구가 중국 본토 표기 기준의 간체 중국어로 표시됩니다.
- 프론트엔드 번역 22종(진입 파일 1종 + partial 21종)을 추가했습니다 — 홈(`home`), 게시판(`board`), 쇼핑몰(`shop`), 마이페이지(`mypage`), 인증(`auth`), 회원(`user`·`userinfo`), 검색(`search`), 약관(`policy`), 오류(`error`), 내비게이션(`nav`)·푸터(`footer`), 업로드·첨부(`upload`·`attachment`), 레이아웃 편집기(`editor`·`layout_editor`), 국가·언어·시간대 목록(`countries`·`languages`·`timezones`), 템플릿 전용(`sirsoft-basic`).
- 초기 데이터 번역 1종을 추가했습니다 — 템플릿 표시명·설명.
- 통화 코드·주문 상태값·라우트 경로·컴포넌트 이름·아이콘 클래스·placeholder 는 원본 그대로 보존했습니다.

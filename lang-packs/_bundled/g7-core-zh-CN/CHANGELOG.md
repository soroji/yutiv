## [1.0.0] - 2026-09-07

### Added

- G7 코어 중국어 간체(zh-CN) 언어팩을 신규 제공합니다. 관리자 화면과 사용자 화면의 코어 문구, 검증 메시지, 오류 안내가 중국 본토 표기 기준의 간체 중국어로 표시됩니다.
- 백엔드 번역 40종을 추가했습니다 — 회원·권한·역할·메뉴·모듈·플러그인·템플릿·테마·언어팩·스케줄·첨부파일·알림·본인인증·환경설정·대시보드·활동 로그·검색·SEO·레이아웃·검증 메시지 전체.
- 프론트엔드 번역을 추가했습니다 — 템플릿 엔진 오류 문구와 레이아웃 편집기 전체 화면(도구 모음·라우트 트리·속성 패널·데이터 소스·페이지 설정·단축키 등).
- 초기 데이터 번역을 추가했습니다 — 코어 권한 트리 84항목, 기본 역할 4종, 관리자 메뉴 12종, 알림 정의·템플릿 5종, 본인인증 메시지 정의 5종.

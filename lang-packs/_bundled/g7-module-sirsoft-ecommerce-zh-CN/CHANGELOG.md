## [1.0.0] - 2026-09-08

### Added

- G7 이커머스 모듈(sirsoft-ecommerce) 중국어 간체(zh-CN) 언어팩을 신규 제공합니다. 관리자 화면과 사용자 화면의 상품·주문·결제·배송·환불 문구, 검증 메시지, 알림 메일이 중국 본토 표기 기준의 간체 중국어로 표시됩니다.
- 백엔드 번역 13종을 추가했습니다 — 관리자·본인인증·주문·리뷰·SEO·환경설정·현금영수증·열거값·예외·활동 로그·메시지·검증 메시지 전체.
- 프론트엔드 번역 36종(진입 파일 1종 + partial 35종)을 추가했습니다 — 상품 관리·주문 관리·환경설정·쿠폰·배송정책·마일리지·개인결제·입금관리 등 관리자 화면과 상품 상세·장바구니·주문/결제 등 사용자 화면 문구.
- 초기 데이터 번역 9종을 추가했습니다 — 역할 1종, 권한 트리 20개 카테고리, 관리자 메뉴 12종, 알림 정의·템플릿 10종, 본인인증 메시지 1종, 클레임 사유 7종, 배송유형 11종, 배송사 12종, 모듈 표시명.
- 상품·주문·결제·배송·환불 관련 내부 enum key/value, 통화 코드(KRW/USD/JPY/CNY/EUR), SKU·PG·API·URL·VAT 등 기술 식별자, 숫자·날짜 포맷 문자열은 원본 그대로 보존했습니다.
